## v8.1.0 - 12-11-2026
### Added
* Store ORT scans from the ort-runner via `POST /v1/scans`, keeping every scan as history, and show the latest scan as `scanSummary` in the repository list and as `scan` on the repository detail, with dependency counts, package managers, ORT findings per repository rule and a score; vulnerabilities are stored but not published.
### Fixed
* CI gebruikt de gedeelde workflows uit developer-overheid-nl/.github; test-images krijgen de tag test-<sha> en overschrijven de productie-image niet meer.
* publiccodeYmlVersion in de OAS is geen enum meer maar een string met een versiepatroon, zodat elke (toekomstige) publiccode.yml-versie geldig is.
